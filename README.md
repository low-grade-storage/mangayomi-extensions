# Mangayomi Custom Extensions Repository

A unified extension catalogue containing custom anime, manga, and novel extensions for [Mangayomi](https://github.com/kodjodevf/mangayomi). Includes web novel and light novel readers, manga sources, and anime streaming providers.

## 1-Click Install

Click the button below on your phone or PC browser to add the complete repository into Mangayomi:

[![Add All Extensions to Mangayomi](https://img.shields.io/badge/Mangayomi-Add%20Custom%20Extensions-blue?style=for-the-badge&logo=android)](https://intradeus.github.io/http-protocol-redirector?r=mangayomi://add-repo?repo_name=Custom%20Extensions%26repo_url=https://github.com/low-grade-storage/mangayomi-extensions%26manga_url=https://raw.githubusercontent.com/low-grade-storage/mangayomi-extensions/main/manga_index.json%26anime_url=https://raw.githubusercontent.com/low-grade-storage/mangayomi-extensions/main/anime_index.json%26novel_url=https://raw.githubusercontent.com/low-grade-storage/mangayomi-extensions/main/novel_index.json)

*(Direct link: [Click here to add to Mangayomi](https://intradeus.github.io/http-protocol-redirector?r=mangayomi://add-repo?repo_name=Custom%20Extensions%26repo_url=https://github.com/low-grade-storage/mangayomi-extensions%26manga_url=https://raw.githubusercontent.com/low-grade-storage/mangayomi-extensions/main/manga_index.json%26anime_url=https://raw.githubusercontent.com/low-grade-storage/mangayomi-extensions/main/anime_index.json%26novel_url=https://raw.githubusercontent.com/low-grade-storage/mangayomi-extensions/main/novel_index.json))*

## Manual Setup

If you prefer to add the catalogues manually in Mangayomi (**More -> Settings -> Browse -> Extension Repositories**):

- **Manga Repository URL**:
  `
  https://raw.githubusercontent.com/low-grade-storage/mangayomi-extensions/main/manga_index.json
  `
- **Anime Repository URL**:
  `
  https://raw.githubusercontent.com/low-grade-storage/mangayomi-extensions/main/anime_index.json

- **Novel Repository URL**:
